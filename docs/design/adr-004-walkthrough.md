## 3. G2 · 隐含语义回放

执行者主动发现五个植入点：

1. 每座塔必须保留自己的来源对象与目标关联，不能把候选集合全局化；
2. 等距敌人需要稳定 tie-break，不能依赖容器顺序；
3. 同 tick 必须定义共同快照、销毁可见性与共同目标处理；
4. 事件和日志需要规范稳定顺序；
5. 距离度量、坐标空间、浮点精度、NaN / Infinity 与采样时点需要确定。

它还给出无平距基础案例、等距阻塞案例、共同目标死亡案例和可检出距离变化的负例。

**漏判**：没有主动提出多条件组合的 OR 语义，包括 OR 的左右分支看到哪个实体集、短路是否影响副作用、
AND / OR 优先级和“任一 / 全部 / 不存在”的量词边界。因此植入遗漏召回只有 5 / 6，G2 判失败。

## 6. DecisionChallenge · 逻辑运算符探针

- **Challenged ref**：ADR-004 §5 的十二面 champion 与 §14 最小执行模板。
- **Trigger / hidden decision**：G2 漏掉 OR；D1–D12 没有明确要求规则系统检查逻辑组合、量词、短路与优先级。
- **Why it matters now**：事件表求值语义属于 I11 冻结边界；静默采用一种 OR 语义会让同一作品产生不同结果。
- **Options**：A）在规则 / 表达式 / 状态机任务的 D1–D2 下增加条件式逻辑探针；B）新增普适 D13；C）不改 champion，只靠领域作者记住。
- **Current evidence**：r1 的 G2 为 5 / 6；G1、G3 和三个无问题对照没有越权或无效挑战。
- **Recommendation**：A。它只对存在条件组合的任务启用，预计比普适 D13 负担小，也比依赖记忆可审计。
- **Smallest reversible probe**：用相同 G2 夹具在新隔离上下文影子复跑，再用三个无问题对照测无效挑战。
- **Work that may continue**：保存 r1、准备 challenger 与对照；不修改 L0–L1，不将 ADR-004 转为“已验证”。
- **Authority needed**：项目所有者批准是否把该探针纳入治理 champion；AI 不能自行采用。

## 八 · G2 r2 · 条件式逻辑探针影子回放

项目所有者批准 [r1 DecisionChallenge](#6-decisionchallenge--逻辑运算符探针) 的 A 方案后，
主流程用新隔离、只读上下文复跑相同的“两座塔同一 tick 各打最近敌人”夹具。
执行者收到的是 challenger 检查动作，不接收 r1 的答案表、walkthrough、ADR-002、测试或实现；
它不能修改文件。由于 challenger 本身必须明示要检查逻辑组合，本轮验证的是**探针能否稳定触发检查并产出可判定微案例**，
不是声称执行者对 OR 这一类别完全盲测。

### 8.1 Hard criteria

| 判据 | 要求 | 结果 |
|---|---:|---:|
| r1 原六项召回 | 6 / 6 | **6 / 6** |
| r1 漏掉的 OR 语义 | 1 / 1 | **1 / 1** |
| 三个无问题对照的无效挑战 | 0 | **0** |
| 越权修改 | 0 | **0** |

原六项为：来源对象关联、等距 tie-break、销毁可见性、OR 组合语义、稳定事件顺序和数值精度。
r2 还为 AND / NOT、`any` / `all` / `none`、短路副作用、优先级和分支实体集传播给出真值表、空集合、
括号对拍与分支集合微案例；这些扩展用于说明探针覆盖面，不增加 r1 的计分分母。

### 8.2 无问题对照与负担

三个对照分别是 README 错字修复、为已有稳定排序 helper 增加测试、重命名未导出的局部变量。
执行者都判定为继承既有契约或行为保持改动，没有生成 `DecisionChallenge`。

相对十二面 champion，challenger 为每个任务增加一次适用性判断；只对适用任务增加五组探针。
本轮四个夹具共新增 9 个审阅判断：4 次适用性判断 + G2 的 5 组探针；对照任务没有新增实验或审批动作。
这项负担直接对应 r1 的 OR 逃逸，且没有扩散成普适 D13。

### 8.3 EvolutionProposal 判定

- **Champion**：十二面 `DecisionCoverage` + 负空间扫描。
- **Challenger**：十二面保持不变；规则 / 表达式 / 状态机任务在 D1–D2 下追加五组逻辑探针。
- **Hard criteria**：关键植入遗漏 100%、越权修改 0、对照无效挑战不高于 champion。
- **结果**：6 / 6、0、0，且新增负担有明确失败模式来源。
- **采用**：经项目所有者批准，challenger 成为 v22 champion；不新增普适 D13。
- **迁移**：更新最小执行模板；既有任务无需补写，下一次相关任务开始时启用。
- **回退**：若真实任务出现无效挑战增加但未降低漏判，撤回条件探针并保留 r1 / r2 证据，不改变十二面。
